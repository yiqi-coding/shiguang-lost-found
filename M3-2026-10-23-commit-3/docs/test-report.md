| 可信度曾是薄弱环节 | M2 首轮实测误通过率 **30.6%**（72 例全错答案中 22 例未判为高风险）。根因：同类别干扰答案与**复合式**参考条目（如「学号 2024XXXXXX，姓名 陈某某」vs 参考「学号 2023XXXXXX，姓名 张某某」）字符 n-gram 相似度偏高，未走关键字段精确匹配。**已按根因修复**（关键字段强校验，非调阈值），误通过率降至 4.2%。 |
| 误拒绝率为 0 | 判定偏"宽"而非偏"严"：宁可交管理员复核，也不错杀真实失主。符合需求「可信度只作辅助依据、不自动确权」的定位。 |
| 响应时间 | 单次 `match_pair` 约 200~330 ms（纯 Python，无向量库）。演示规模下满足需求 §13.4「缓存匹配结果 P95 < 1 秒」。 |

> ⬆ 上表为 M0 空白模板，保留作对照。以下为 M2 阶段由脚本自动回填的实测结果。

|---|---|---:|---:|---:|---:|

- **关于 C 与 D 并列**：两者 MRR 相同，即在本数据集上图像分未带来额外排序增益。原因是 Mock 图像向量由文本特征派生、与属性分高度相关。**这不代表图像分无效**，而是当前 Mock 实现的局限；接入真实多模态模型后需重新评测。
