# 拾光 · 用户使用手册

> 适用对象：普通用户（失主 / 拾到者）、管理员、评委与演示操作者
>
> 版本：Baseline v1.0 ｜ 更新日期：2026-09-30

---

## 0. 一分钟了解拾光

拾光是一个**校园失物与拾物**的匹配与认领平台。它和普通失物招领板的区别在于：

1. **描述不一样也能匹配上** —— 你说「耳机」，对方说「蓝牙耳机」，系统通过图文、时间、地点综合打分，而不是只比对关键词；
2. **分数是算出来的，不是猜的** —— 每个候选都给出六个维度的分数与加权过程，还列出「匹配依据」和「不确定因素」；
3. **不是谁都能领走** —— 认领人要回答只有真正物主才知道的**隐藏特征问题**，系统算出可信度供管理员参考；
4. **最终由人决定** —— 系统**不会**自动判定所有权，认领必须经管理员审核通过。

> ⚠ **重要声明**：本系统提供候选匹配和辅助审核建议，**不构成物品所有权的自动认定**。最终认领结果由平台管理员根据匹配依据、验证结果和实际交接情况确认。

## 1. 角色与能做什么

| 角色 | 可以做什么 | 不能做什么 |
|---|---|---|
| **游客** | 浏览物品列表与详情、查看公开的匹配结果 | 不能发布、不能认领、看不到隐藏特征 |
| **普通用户（失主/拾到者）** | 发布失物/拾物、上传图片、查看自己的记录与匹配结果、发起并完成认领验证 | 看不到别人记录的隐藏特征、不能直接改物品状态、看不到验证标准答案 |
| **管理员** | 查看全部记录与隐藏特征、审核认领、处理争议、查看审计日志 | 不能绕过审核流程直接改状态（所有操作都留痕） |

## 2. 新用户第一步

1. 打开平台首页，点击右上角「登录」；
2. 演示环境可直接使用演示账号（见 §7），或用组织方分配的账号登录；
3. 登录后右上角出现「我的记录」入口；管理员账号会额外出现「管理台」。

## 3. 我丢了东西 —— 发布失物

**入口**：顶部导航「发布失物」

### 3.1 填写基础信息

| 字段 | 是否必填 | 建议 |
|---|:--:|---|
| 物品类别 | ✅ | 从 7 个类别中选择；选「其他」会降低匹配效果 |
| 标题 | ✅ | 5~80 字。写「丢失一副黑色无线耳机」比「丢东西了」有用得多 |
| 详细描述 | ✅ | 10~2000 字。**多写细节**：何时何地、当时在做什么、物品外观、有无特殊标记 |
| 颜色 / 品牌型号 | ⭕ | 能填就填，这两项会显著提高匹配准确度 |
| 丢失地点 | ✅ | 尽量写到具体位置，如「图书馆三楼靠窗自习区」 |
| 丢失时间 | ✅ | 越精确越好，系统用时间差判断合理性 |
| 联系方式 | ⭕ | 会自动脱敏存储（如 `138****8888`） |

### 3.2 上传图片

- 支持 JPG / PNG / WEBP，单张不超过 10 MB，最多 3 张；
- 建议提供**能看清特征**的照片（划痕、贴纸、配件是否齐全）；
- 图片仅用于匹配与人工核验，不会无条件公开原图。

### 3.3 填写公开特征与隐藏特征 —— **这是最关键的一步**

**公开特征**（所有人可见）：用于帮助他人判断是否是同一件物品。
> 例：`椭圆形充电盒`、`盒体有轻微使用痕迹`

**🔒 隐藏特征**（仅你和管理员可见）：用于**认领验证**，只有真正的物主才答得出来。
> 例：`盒盖内侧有一道约 3 厘米的划痕`、`蓝牙名称 YiQi-AirPods`

填写建议：

| 类型 | 好例子 | 为什么 |
|---|---|---|
| 外观痕迹 | 盒盖内侧有一道约 3 厘米的划痕 | 位置 + 长度，别人猜不到 |
| 设备名称 | 蓝牙名称 YiQi-AirPods | 唯一性强，可精确比对 |
| 个性贴纸 | 背面贴了一张校运会贴纸，右上角翘起 | 细节具体 |
| 内部内容 | 卡套里夹着一张写着宿舍号的便签 | 只有本人知道 |
| 配件缺失 | 左耳塞的耳帽丢了，只剩右耳 | 具体的缺失情况 |
| 特殊磨损 | 杯底有一处磕碰掉漆，直径约 5 毫米 | 尺寸 + 位置 |

> ❌ **不要填**：`很重要`、`我的东西`、`丢了很久了` —— 这类描述无法用于验证，也帮不上匹配。
>
> ⚠ 隐藏特征**至少填 1 条**，建议填 2~3 条。填得越具体，冒领的人越难蒙混过关。

### 3.4 提交后的 AI 分析

提交后系统会自动提取物品属性（类别、颜色、品牌、可见特征、关键词等）：

- **成功**：弹出「AI 提取结果」抽屉，你可以**修改任何一项**。你自己修改的内容优先级高于 AI 的自动结果；
- **失败**：顶部会出现提示「AI 分析失败，请手动补充物品属性」——**这不影响发布**，物品已经成功创建，你可以手动补充。

> AI 结果只是**辅助**，可能不准确，也会标注「不确定项」。请以你自己的判断为准。

## 4. 我捡到东西 —— 发布拾物

**入口**：顶部导航「发布拾物」

流程与发布失物完全一致，区别在于：

| | 发布失物 | 发布拾物 |
|---|---|---|
| 时间字段 | 丢失时间 | 拾取时间 |
| 描述重点 | 当时在哪、物品有什么特征 | 在哪发现的、当时状态、是否已交到某处 |
| 隐藏特征引导 | 「只有你能答出的细节」 | 「只有真正失主才知道的细节」 |

> 💡 **拾到者的隐藏特征怎么填？** 填你观察到的、照片上看不出来的细节。例如你捡到耳机时发现「充电盒里只有左耳」，而失主发布时写「左右耳机都在」，这个矛盾本身就是重要的验证信息。

## 5. 查看候选匹配

**入口**：物品详情页 →「查看候选匹配」

页面会展示按总分排序的 Top 5 候选，每个候选包含：

### 5.1 六维分数与加权过程

```text
类别一致        ████████████████████████ 1.00  ×0.20 = 0.200
属性/文本       ██████████████████████░░ 0.92  ×0.25 = 0.230
图像相似度      ███████████████████░░░░░ 0.81  ×0.20 = 0.162
时间合理度      ███████████████████████░ 0.95  ×0.15 = 0.143
地点合理度      ████████████████████████ 1.00  ×0.15 = 0.150
品牌/型号       ████████████░░░░░░░░░░░░ 0.50  ×0.05 = 0.025
                                    总匹配分 = 0.88  [ 高匹配 ]
```

### 5.2 三种辅助信息

| 信息 | 含义 | 怎么用 |
|---|---|---|
| ✓ **匹配依据** | 支持「这两条记录可能是同一件物品」的理由 | 逐条看是否说得通 |
| ⚠ **不确定因素** | 无法确认的地方（品牌没填、拍摄角度不同等） | 重点核对这几项 |
| ⚠ **风险提示** | 该类别是否高仿冒风险、是否需要重点核验 | 决定是否要额外验证 |

### 5.3 匹配等级

| 等级 | 总分 | 含义 |
|---|---|---|
| 高匹配 | ≥ 0.75 | 多条依据吻合，值得进一步核实 |
| 中匹配 | 0.50 ~ 0.75 | 有相似之处，但存在明显差异 |
| 低匹配 | < 0.50 | 相似度低；低于 0.35 的候选默认不展示 |

> ⚠ **候选匹配不等于确认归属**。高分只代表「值得核实」，不代表「就是你的」。

## 6. 发起认领与验证

**入口**：匹配结果页 → 找到你的物品所在记录 →「这是我的，发起认领」

### 6.1 回答问题

系统会根据对方填写的隐藏特征生成 2~3 个问题，例如：

```text
问题 1/3  请描述充电盒上的特殊痕迹（位置、形状或长度）。
问题 2/3  请填写该设备设置的蓝牙名称。
问题 3/3  请说明耳机盒内是否缺失某个配件。
```

**答题要点**

- 用你自己的话描述，不必和对方写法完全一致 —— 系统能识别同义表达（「划痕」与「刮痕」、「右侧」与「右边」）；
- 但**设备名称、编号这类关键信息要尽量准确**（大小写和空格不影响）；
- 不确定的题可以留空，但会拉低可信度；
- **答题次数最多 3 次**，用完后会转交管理员人工处理。

> 🔒 **系统不会显示标准答案**，你的回答只用于计算可信度，供管理员参考。草稿只保存在你自己的浏览器里，不会上传。

### 6.2 查看验证结果

提交后你会看到：

| 项 | 说明 |
|---|---|
| 隐藏特征匹配分 | 你的回答与隐藏特征的吻合程度（0~1） |
| 可信度分 | 综合分数：隐藏特征 60% + 匹配总分 20% + 信息完整度 10% + 风险规则 10% |
| 风险等级 | 低风险 ≥ 0.75 / 中风险 0.45~0.75 / 高风险 < 0.45 |
| 逐题结果 | 每题是否命中、得分与理由 |

> ⚠ 可信度**只是辅助审核依据**，不等于认领成功。**验证通过后状态只会变成「待管理员审核」，不会自动变成「已认领」。**

## 8. 管理员操作

**入口**：顶部「管理台」

### 8.1 审核工作台

左侧是待办列表（**高风险与连续验证失败的会置顶**），右侧单页展示决策所需的全部信息：

- 匹配总分与六个维度分
- 匹配依据、不确定因素
- **双方填写的隐藏特征**（对照查看）
- 隐藏特征验证结果（逐题是否命中 + 得分 + 理由）
- 可信度分与风险等级
- 双方账号与脱敏联系方式
- 历史操作日志
- 当前物品状态

> 管理员查看隐藏特征属于授权行为，**本次查看会记入审计日志**。

### 8.2 三种审核动作

| 动作 | 效果 | 备注 |
|---|---|---|
| ✓ 通过认领 | 物品状态变为「已认领」 | 备注可选 |
| ✕ 驳回 | 物品状态变为「已驳回」 | **备注必填**（10~500 字） |
| ↺ 要求补充信息 | 状态变为「待补充信息」 | **备注必填**，说明要补什么 |

另有「暂停物品」「标记争议」「关闭记录」用于异常处理。

### 8.3 审核原则

1. **可信度只是参考**，不能因为分数高就直接通过 —— 必须结合匹配依据与实际情况；
2. 出现「不确定因素」时，优先核对那几项；
3. 高风险类别（如校园卡、耳机）建议要求提供额外证明；
4. 备注要写清判断理由，这是后续追责与复盘的依据。

### 8.4 审计日志

**入口**：管理台 →「审计日志」

可按对象类型、对象 ID、操作人、动作、时间范围查询。每条记录包含操作人、角色、对象、动作、脱敏详情、请求追踪 ID。

> 审计日志**只增不改**，数据库层面对应用账号不开放修改与删除权限。

## 9. 常见问题（FAQ）

**Q1：AI 分析失败了，我的发布算成功吗？**
算成功。物品已经创建，只是属性需要你手动补充。点详情页的「补充属性」即可。

**Q2：为什么我的物品没有匹配到任何候选？**
可能原因：① 描述过于笼统；② 类别选错；③ 目前确实还没有人发布对应的记录。建议补充颜色、品牌、地点等细节后点击「重新计算」。

**Q3：我看到别人记录的隐藏特征了吗？**
没有。普通用户在任何页面都看不到他人记录的隐藏特征，这是**后端接口层面**的限制，不是前端隐藏。

**Q4：我答对了为什么还是「待审核」？**
这是设计如此。**系统不会自动判定所有权**，验证通过只是把申请提交给管理员。

**Q5：验证失败 3 次怎么办？**
状态会转交管理员人工处理，并附上风险标记。请联系管理员线下核验。

**Q6：为什么我的联系方式显示成 `138****8888`？**
这是脱敏处理。完整联系方式不会展示在页面上，也不会写入日志。

**Q7：「重新计算」按钮是做什么的？**
忽略缓存重新计算匹配。当对方补充了描述、或你修改了自己记录的信息后，用它获取最新结果。

**Q8：页面提示「算法服务暂不可用，当前为规则匹配降级结果」是什么意思？**
系统的智能匹配服务暂时不可用，已自动降级为规则匹配，**业务仍可正常使用**，只是精度下降。稍后点「重新计算」即可恢复。

**Q9：怎么找到我的历史记录？**
右上角「我的记录」，分「我发布的」和「我认领的」两个标签页。

**Q10：手机上能用吗？**
可以。页面做了响应式适配，手机宽度下基本可用（但不提供原生 App）。

## 10. 联系与反馈

| 事项 | 处理方式 |
|---|---|
| 认领纠纷 | 通过管理台「标记争议」，由管理员介入 |
| 误发布 / 需要修改 | 联系管理员修改记录状态 |
| 系统故障 | 记录页面上的**请求追踪 ID**（错误提示中会显示），提供给运维人员，可快速定位日志 |
